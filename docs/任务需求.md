# X5 RetailHero：短信营销 Uplift 建模任务

整理日期：2026-11-12。本文根据官方网页整理为中文摘要，非逐字翻译。文中“官方要求”与“建议实施内容”分别标注。

> 本文中的数据与来源路径均以项目根目录为基准。

## 1. 任务要求
### 业务背景与目标

X5 通过短信鼓励客户购买，但发送短信存在成本。任务是识别哪些客户会因为短信而增加购买概率，据此决定优先向谁发送短信。[1]

模型需要估计营销带来的**增量效果（Uplift）**，而不只是客户本身的购买概率。可以用以下表达帮助理解：

```text
Uplift(x) = P(购买 | 发送短信, x) − P(购买 | 不发送短信, x)
```

上式是建模解释；因果解释还依赖实验分配及其他识别条件，不能直接把普通观察数据的条件概率差当作因果效果。每个客户只能观察到一种处理状态，数据没有直接提供个人真实 Uplift 标签。

### 评价指标

官方按预测 Uplift 从高到低排列测试客户，选取**前 30%**，评价该人群的平均增量转化。[1]

对有处理组和对照组标签的验证集，可以按这一口径计算：

```text
S = 按预测 Uplift 排名前 30% 的客户
Uplift@30% = S 内处理组购买率 − S 内对照组购买率
```

这是对官方文字口径的公式化说明；若复现竞赛评分，应再以官方基线代码核对取整、并列分数等细节。AUUC、Qini、分类 AUC 可作为补充，不能替代官方主指标。

来源：[官方任务与评分说明][1]。

## 2. 本地数据与使用要求

官方提供客户、商品、触达前购买记录、实验训练集、测试客户和提交样例。[2] 当前项目文件均位于 `data/`，已于 2026-11-12 解压为 CSV，校验通过后已删除原 `.csv.gz` 文件：

| 本地文件 | 作用 |
| --- | --- |
| `data/clients.csv` | 客户基本信息 |
| `data/products.csv` | 商品信息 |
| `data/purchases.csv` | 营销触达前的购买明细，用于构建历史特征 |
| `data/uplift_train.csv` | 训练客户及处理、购买标签 |
| `data/uplift_test.csv` | 需要预测 Uplift 的测试客户 |
| `data/uplift_sample_submission.csv` | 提交格式示例 |

关键字段：[2]

| 字段 | 含义 |
| --- | --- |
| `client_id` | 客户标识，建议作为字符串读取，保留前导零 |
| `treatment_flg` | 是否接受营销触达 |
| `target` | 触达后观察期内是否购买 |

实际字段以本地文件表头为准。可参考 `docs/sources/` 中的下载来源说明；其中旧示例的 `raw/` 路径应替换为当前实际的 `data/`。

## 3. 输出格式

为 `uplift_test.csv` 中每位客户输出一个分数，CSV 包含两列：[2]

```csv
client_id,uplift
example_client_a,0.08
example_client_b,-0.02
```

## 4. 自行设置实施内容

以下内容用于将原竞赛扩展为“零售用户分析、营销评估与 Uplift 优化”项目。

| 阶段 | 工作内容 | 验收产物 |
| --- | --- | --- |
| 数据检查 | 主键、缺失、异常、关联覆盖率；核对处理组与对照组规模及特征差异 | 数据质量报告与字段字典 |
| 客户消费分析 | RFM、客单价、品类偏好、消费频率与客户分层 | 用户画像与分层分析 |
| 营销效果评估 | 总体及分层购买率差异、置信区间；检查实验分配背景 | 增量转化分析报告 |
| 客户特征构建 | 汇总触达前历史消费行为，明确每个特征的时间边界 | 客户级建模表与生成代码 |
| 基线建模 | 随机排序、普通购买概率模型、T-Learner；再考虑 S-Learner 或更复杂方法 | 在同一划分上的模型比较 |
| 策略评估 | 主看 Uplift@30%，补充多种触达比例、Uplift 曲线与 Qini/AUUC | 预算与触达比例建议 |
| 预测交付 | 为全部官方测试客户预测分数 | 格式正确的预测 CSV |

### 实施约束与解释边界

- 从有标签训练集划分本地训练、验证、测试数据；客户不能跨集合重复。调参使用验证集，最终保留集只做最终评价。
- 所有行为特征来自营销触达前，不能使用结果期信息。
- 普通购买概率高不代表短信增量高，应通过同一验证口径比较。
- 如果没有官方测试集标签，只能检查预测覆盖与格式，不能计算它的真实得分。
- 利润模拟需要短信成本、毛利等参数。数据未提供时明确标注假设，不能声称模拟利润为实际收益。
